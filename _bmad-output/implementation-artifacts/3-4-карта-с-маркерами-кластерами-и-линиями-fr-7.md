## Acceptance Criteria

**AC1 — Маркеры/линии/кластеры при плотности, статус несёт форма/глиф, z-priority** [Source: epics.md:1286-1288]
**Given** MapLibre GL 5 + PMTiles, bbox-загрузка объектов (GeoJSON `[lon,lat]`)
**When** карта отображается при плотности
**Then** маркеры/линии/кластеры (supercluster `clusterRadius≈50`, `clusterMaxZoom≈15`); статус маркера несёт ФОРМА/глиф (пустой/«!»/«✓»/двойное кольцо), цвет вторичен (WCAG 1.4.1); z-priority выбранный>флаг>обычный.
*Уточнение к реальности кода:* MapLibre GL **5.24.0** и pmtiles **4.4.1** уже запинены [web/package.json:21-22]; PMTiles-ПОДЛОЖКА Астаны в 3.4 НЕ делается (`BASEMAP_PMTILES_URL=undefined`, нейтральный фон — экстракт planetiler отложен S-0.5, AR-23) — «PMTiles» в Given = уже готовый протокол/механизм [shared/map/pmtilesProtocol.ts]. Глифы: пустой = обычный (auto/manual), «!» = **есть активный риск-флаг** (`has_active_flag`, НЕ гео-статус), «✓» = `geocode_status='verified'` (D3), двойное кольцо ×1.25 = выбранный. Линии = LINESTRING дорог (голубая, casing + пунктир; выбранная — золотой stroke) [EXPERIENCE.md:220; DESIGN.md:241].

**AC2 — Кластер с флаг-объектами несёт амбер-кольцо; тап → плавный зум** [Source: epics.md:1290-1292]
**Given** кластер с флаг-объектами
**When** он свёрнут
**Then** несёт амбер-кольцо с «!»-точкой (флаг не теряется); тап → плавный зум к раскрытию.
*Уточнение:* «флаг-объект» = объект контракта с активным риск-флагом ⇒ выдача bbox-эндпоинта ОБЯЗАНА нести `has_active_flag` (расширение ридера, Task 1). Кольцо — токен `signal-attention` (амбер, НЕ алый), кольцо+«!»-точка = не-цветовой признак [DESIGN.md:248; EXPERIENCE.md:221]. Плавный зум уважает `prefers-reduced-motion` (паттерн `PREFERS_REDUCED_MOTION` уже в MapView) — полный a11y-проход = 3.8.

**AC3 — Аффорданса-счётчик «Ещё N объектов без точки на карте»** [Source: epics.md:1294-1296]
**Given** часть объектов района без точки
**When** порог фолбэка не достигнут
**Then** на карте видна аффорданса-счётчик «Ещё N объектов без точки на карте → открыть списком».
*Уточнение:* порог/фолбэк-РЕЖИМ = 3.3/3.6 (не здесь); в 3.4 счётчик виден при N>0 всегда. N = контракты Астаны без точки: `geocode_status='unmatched'` ИЛИ вовсе без гео-строки, `NOT is_deleted` (D4). «Открыть списком» → `/search` (поиск+фильтры 6.1/6.2; фолбэк-список района = 3.6). Честность: unmatched в bbox-выдачу не попадает структурно (honesty-CHECK: geom NULL ⟺ unmatched) — счётчик и есть их видимость на карте (`{data-state-ungeocoded}` [EXPERIENCE.md:255]).
