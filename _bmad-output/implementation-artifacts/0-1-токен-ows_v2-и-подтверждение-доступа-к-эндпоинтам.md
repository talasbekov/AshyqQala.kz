# Story 0.1: Токен ows_v2 и подтверждение доступа к эндпоинтам

Status: in-progress

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a **команда платформы AshyqQala.kz**,
I want **получить `GOSZAKUP_TOKEN` и подтвердить доступ к нужным эндпоинтам ows_v2**,
so that **гейт №0 и будущий импорт работают на официальном канале (ows_v2 по токену), а не на парсинге портала** (несущий принцип проекта).

> **Тип истории:** enabler-story Эпика 0 (без FR). Снимает **Блокер №0** (наличие токена) и
> является воротами для Epic 2 (импорт) и Epic 3 (геопривязка). Несёт AR-2.
> **Важно:** часть AC — это человеко-операционные действия (получение токена через
> профиль участника goszakup.gov.kz, юр-изоляция доступа), которые dev-агент НЕ может
> выполнить за человека. Dev-агент отвечает за: проверяемую часть (200 OK по эндпоинтам
> через инструмент), фиксацию КАТО-карты районов, определение фильтра направлений на
> выборке и документирование результатов. Действия, требующие человека, помечены 👤.

## Acceptance Criteria

**AC1 — Токен получен и изолирован** 👤
**Given** профиль участника на goszakup.gov.kz
**When** запрошен токен ows_v2
**Then** токен получен и хранится в секрет-сторе VPS (вне репозитория), доступ изолирован.

**AC2 — Эндпоинты отвечают 200 OK**
**Given** валидный токен
**When** отправлен тестовый запрос к `/v2/journal`, договорам (`/contract`), лотам (`/lots`),
`/v2/trd-buy`, участникам, `/v2/rnu`, `/v2/acts`
**Then** каждый эндпоинт отвечает `200 OK`.

**AC3 — Зафиксирована КАТО-карта районов Астаны**
**And** список КАТО районов Астаны (Алматы, Сарыарка, Есиль, Байконыр, Нура) зафиксирован
(конкретные коды районов, не только префикс «71»).

**AC4 — Определён фильтр направлений на выборке**
**And** фильтр «дороги»/«водоснабжение» по предмету/коду закупки определён на выборке
(подтверждена применимость существующих ключевых слов и/или кодов закупки).

### Соблюдение архитектуры (guardrails)

- **Официальный канал, не парсинг.** Доступ — только `ows_v2` по токену. `-source scrape`
  существует, но **юридически ограничен** (нарушает несущий принцип §6.1/§6.4) — НЕ использовать
  для этой истории. [Source: _bmad-output/planning-artifacts/architecture.md строки 94, 100]
- **Изоляция токена (несущий инвариант на будущее).** В целевой архитектуре `cmd/importer`
  держит `GOSZAKUP_TOKEN` и пишет; `cmd/api` токена **не видит**. Секреты — env/секрет-стор
  VPS, вне репо, с ротацией. Документировать AC1 в этих терминах.
  [Source: _bmad-output/planning-artifacts/architecture.md строки 100, 390–391]
- **Схемная устойчивость (намеренная).** Парсер `stage0-audit` никогда не предполагает точные
  имена полей API: `models.go` маппит логическое поле на список кандидатов (`fieldCandidates`),
  первый непустой выигрывает; неизвестная схема даёт `""`/`0` и честно показывается в метриках
  полноты, без падения. Если `-probe` показал ДРУГОЕ имя поля — **добавить кандидата** в список,
  а не менять логику. [Source: CLAUDE.md «Key conventions», stage0-audit/models.go]
- **VERIFY-маркеры** в `config.go`/`models.go` — это допущения, которые именно сейчас (на живом
  токене) надо подтвердить: префикс КАТО «71», имена полей суммы/БИН/дат/КАТО/anno, и **источник
  числа участников** для флага «единственный участник». [Source: CLAUDE.md, stage0-audit/models.go]
- **Честность над домыслом.** Неподтверждённое (например, точный КАТО-код района) фиксируется
  как «нет данных» / вопрос владельцу. Не интерполировать и не выдумывать.
