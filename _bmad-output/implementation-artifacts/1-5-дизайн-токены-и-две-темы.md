# Story 1.5: Дизайн-токены и две темы

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a **разработчик фронта**,
I want **дизайн-токены из единого источника (`tokens.json` DTCG → свой codegen → CSS-переменные + типы) с двумя темами на одних семантических именах**,
so that **визуал консистентен, доступен (WCAG 2.1 AA) и переключается между светлой/тёмной темой БЕЗ знания темы компонентами** (визуальная честность/нейтральность — структурой, а не дисциплиной).

> **Тип истории:** enabler-story Эпика 1 (фронтовый фундамент). Без FR напрямую; несёт UX-DR1…DR6
> (токен-пайплайн, 3-слойная грамматика, две темы, палитра, WCAG, типографика) и a11y-гардрейлы.
> Ставит токен-систему для всех будущих компонентов (карточки 1.7+, карта Epic 3, флаги Epic 4).
> **Предусловия выполнены:** `web/` (Vite+React+TS+ESLint+Prettier, 1.1) существует; `make gen-tokens`
> и `web/src/shared/tokens/` есть как каркас. Task 0-HALT не нужен.

## Acceptance Criteria

**AC1 — `tokens.json` (DTCG) → свой codegen → `tokens.css` + `tokens.ts`, покрыто golden-снапшотом (red-first)**
**Given** `web/tokens.json` в форме W3C DTCG (значения — из `DESIGN.md`, НЕ выдуманные)
**When** `make gen-tokens` (свой codegen `web/scripts/tokens-codegen.mjs`, **БЕЗ Style Dictionary/Tailwind**, ноль зависимостей)
**Then** детерминированно генерятся `web/src/shared/tokens/tokens.css` (`:root` + `[data-theme=dark]`) и `tokens.ts` (типизированные семантические имена); вывод стабилен при повторе (для drift-стража); покрыт golden-снапшотом vitest, написанным **red-first**.

**AC2 — Семантические токены — закрытый list-enum; primitive и хардкод запрещены stylelint**
**Given** трёхслойная модель (primitive приватны → semantic — закрытый list-enum → component-алиасы)
**When** фича использует значение
**Then** только **semantic**-имена; primitive в фичах запрещены; хардкод цвет/размер-литералы в CSS и `outline:none` **без замены** блокируются **stylelint** (red в CI). Токен-определяющие файлы (`tokens.css`) — исключены из правила «без hex».

**AC3 — Две темы одними семантическими именами; компоненты темы не знают**
**Given** две темы (light + dark) на одних semantic-именах, разные значения
**When** переключается атрибут `[data-theme]` (`:root` = light по умолчанию, `[data-theme=dark]` = переопределения)
**Then** компоненты темы НЕ знают (никакой `dark:`-логики в React); тёмная тема — НЕ инверсия, а свои значения из `DESIGN.md`; bootstrap применяет тему из `prefers-color-scheme` + сохранённого выбора.

**AC4 — Контраст-тест-каркас готов; drift-страж токенов в CI**
**Given** WCAG 2.1 AA (текст ≥4.5:1; крупный/UI ≥3:1; focus-ring ≥3:1 к ОБЕИМ темам)
**When** прогон тестов и CI
**Then** есть контраст-тест-каркас (чистая функция ratio + проверка ключевых пар токенов: focus-ring, text-primary/surface, link-on-sunken на обоих фонах), **готовый активироваться с первым цветом флага**; CI-страж `generated==regenerated` для `tokens.css`/`tokens.ts` (паттерн Story 1.4) красит merge при дрейфе; stylelint-шаг добавлен в `ci-web.yml`.
