# Story 6.3: Агрегаты района

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a гражданин,
I want сводку по своему району,
so that я вижу масштаб трат и сигналов рядом.

Реализует **FR-17** (агрегаты Района — число объектов, суммы, число активных Флагов, список объектов; Район по КАТО независимо от Геопривязки) [Source: epics.md:114-115, 1694-1708]. Поверхность — `UC-05` (страница района).

## Acceptance Criteria

1. **Сводка района по КАТО (FR-17).**
   **Given** страница района `GET /api/districts/{kato}`
   **When** она открыта по КАТО-коду района Астаны
   **Then** показаны: **число объектов**, **сумма** (₸), **число активных флагов**, **список объектов** (каждый — ссылка на карточку контракта). Район определяется **по КАТО независимо от Геопривязки**: негеопривязанные объекты учтены в агрегатах, и их количество показано отдельной строкой «N объектов без точки на карте». [Source: epics.md:1702-1704; architecture.md:402; ux key-district.html:233-236, 312-319]

2. **Честное пустое/неполное состояние — `container_state` отдельной строкой (AR-17).**
   **Given** район без объектов и/или без активных флагов
   **When** сводка пуста или частична
   **Then** `container_state` виден **отдельной строкой** (`no_contracts` / `no_flags_raised` / `not_geocoded`, различимы) — тишина пустого экрана **никогда** не читается как «всё чисто». Сумма не показывается как «0 ₸», если данных нет. [Source: epics.md:243-245, 1706-1708; architecture.md:885-887]

3. **Невалидный КАТО → честная ошибка; неизвестный-но-валидный → честные пустые агрегаты.** *(текст приведён к реализованному — code-review patch P1, решение владельца Q1 вариант А)*
   **Given** `{kato}` не-цифровой / вне формата (цифры 2..11) ЛИБО валидный КАТО без контрактов
   **When** запрос выполнен
   **Then** невалидный КАТО → `400 {"error":{"code":"VALIDATION_FAILED",...}}`; неизвестный-но-валидный КАТО → `200` с честными пустыми агрегатами (`container_state:["no_contracts"]`), **НЕ 404** — нет авторитетного списка районов для отказа (КАТО-коды не подтверждены до Story 0.1; «коды не выдумываем», stage0-access §3). [Source: apierr/codes.go; epics.md:1706-1708]

4. **Нейтральность поверхности (гардрейл).**
   **Given** любые строки страницы района (kk + ru)
   **When** они отрендерены
   **Then** ноль табу-токенов (`taboo_lexicon.json`), kk↔ru паритет ключей, каждый сигнал в рамке «сигнал, требующий проверки»; агрегат флага монополии назван **«Преобладание подрядчика в районе»**, НЕ «монополия». [Source: ux key-district.html:26-27, 255-256, 260; registry/values/taboo_lexicon.json; frame.signal i18n]

## Dev Notes

### Архитектурные опоры (citable)
- **URL-схема:** `GET /api/districts/{kato}` — публичный id в URL = КАТО-код района; query snake_case, JSON snake_case на проводе (`json`==OpenAPI==`db` дословно; acronyms lower: `kato`). [Source: architecture.md:522-524]
- **Деньги:** `bigint` целые тенге, суффикс `_tng`, **в JSON строкой** (>2^53 теряет точность в JS); формат — `formatMoney`/`Intl.NumberFormat`. [Source: architecture.md:557-558]
- **Две оси честных состояний** (Story 1.4, AR-16): `value_state` (11) и `flag_state` (4) — источник `registry/values/honest_states.json`, Go-консты `registry.go:19-52`, проекция на фронте через `schema.gen.ts` `StringField.state`. Рендер ОБЯЗАН иметь default-ветку. [Source: architecture.md:546-553; registry.go:19-57]
- **Третья ось — `container_state` (AR-17):** закрытый набор `no_contracts`/`no_flags_raised`/`not_geocoded`. **Нет в Go-реестре** (architecture-only); прецедент 0.8 разрешает «ввести как закрытый набор на проводе ИЛИ деривацию на фронте». Видим отдельной строкой. [Source: epics.md:243-245; architecture.md:885-887; 0-8.md:208-211; MapStatePlaque.tsx:3-6]

### Ключевые решения (Decisions) — приняты как дефолт, вынесены вопросами в конце
- **D1 — Членство по КАТО:** реестр `astana_districts.json` хранит префикс района; контракт принадлежит району при `c.kato_code LIKE prefix||'%'`. Причина: КАТО иерархичен, контракт может нести локалити под районом; точный матч пропустит подчинённые локалити. *(Альтернатива — точный `kato_code = $1`; зависит от реальной гранулярности данных goszakup, которую фиксирует заблокированная 0.1.)*
- **D2 — `container_state` на проводе как МАССИВ** закрытого enum (`no_contracts`/`no_flags_raised`/`not_geocoded`). Причина: значения co-occur (например, есть объекты, но 0 флагов И есть негеопривязанные); единый скаляр это не выразит. Server-authoritative → тестируемо через OpenAPI.
- **D3 — Список объектов встроен** в ответ района ограниченной страницей (прецедент `ContractorCard` встраивает контракты), агрегаты считаются по ВСЕМ объектам. «Показать все» → опциональный `kato`-фасет на `/api/contracts` (стретч/деферред).
- **D4 — `flags_by_type` включён** (не только総 total): AC1 требует «число активных флагов» (total), но макет рисует разбивку по типам — она дёшева (тот же GROUP BY) и нужна блоку «Сигналы района». Total = сумма `flags_by_type`.
- **D5 — Миграция-индекс `0018` включена** в 6.3 (NFR-1 несёт Epic 6). Для пилотного объёма seq-scan терпим, но индекс — правильный дом здесь.
