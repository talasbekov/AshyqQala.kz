# Story 1.9: Вертикальный срез «3 читаемых контракта-истории» (демо-фундамент)

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a **гражданин (и жюри конкурса)**,
I want **увидеть один контракт, рассказанный целиком**,
so that **ценность платформы понятна и проверяема при любом проценте автогеопривязки**.

> **Тип истории:** фронтенд-история Epic 1 (демо-фундамент). Несёт **вертикальный срез поверхностей
> FR-11/12/23/28 на РУЧНЫХ данных** (полные версии — Epic 4 compute / Epic 5 presentation). Идёт **на
> синтетике**, без токена ows_v2, без живого Nominatim и без вердикта гейта №0.
> [Source: epics.md:565,830,999–1021]

## Acceptance Criteria

**AC1 — Карточка рассказывает контракт целиком** [epics.md:1007–1009]
**Given** 3 захардкоженных реальных контракта-истории (из Story 0.4)
**When** открыта карточка
**Then** показаны: данные контракта, бейдж нейтрального флага «… — сигнал, требующий проверки»
(evidence вписан вручную через `render`), экран методики (формула ×1.5, evidence, `methodology_version`,
«как пересчитать вручную»), ссылка-первоисточник goszakup ↗.

**AC2 — Gate нейтральности** [epics.md:1011–1013]
**Given** gate нейтральности
**When** показан бейдж флага
**Then** рядом доступны путь к методике **И** минимальная дверь «Сообщить об ошибке» (mailto/форма-stub);
**без обоих флаг НЕ публикуется**.

**AC3 — Дисциплина честности** [epics.md:1015–1017]
**Given** дисциплина честности
**When** показаны 3 истории
**Then** хотя бы одна демонстрирует реальное честное состояние («без точки на карте» или «нет данных»),
а не только успех.

**AC4 — Гео-независимость** [epics.md:1019–1021]
**Given** гео-независимость
**When** срез запускается
**Then** он работает без живого Nominatim и без вердикта гейта №0 (ручные evidence/координаты).

## Dev Notes

### Контекст истории (зачем и где границы)

Epic 1 показывает **первую читаемую единицу ценности целиком**: карточка → нейтральный флаг → методика
(×1.5, как пересчитать) → первоисточник → дверь «Сообщить об ошибке». Это гео-независимый демо-фундамент
для жюри, стоящий при любом % автогеопривязки. Story 1.8 (done) дала карту/превью→карточку и состояние
«без точки на карте»; **1.9 наполняет карточку флагом + методикой + gate нейтральности на РУЧНЫХ evidence**.
[Source: epics.md:550–565,999–1021]

### 🔑 Ключевое решение: ручные данные, НЕ расширять API

**В API нет полей флага/методики/evidence**, таблиц `risk_flags`/`methodology` нет, бэкенд `render.Renderer`
готов но к хендлеру НЕ подключён. AC1 говорит «evidence вписан вручную через `render`» — это про
**нейтральную рамку** (`frame.signal` + `flag_state`), а не про обязательное сетевое поле.

- **НЕ расширять** `Contract` wire/OpenAPI/sqlc под флаги, **НЕ создавать** таблицы/миграции, **НЕ подключать**
  `render` к API — всё это Epic 4 (реальный compute) / Epic 5 (публикация флага на карточке).
- **Делать:** ручные флаги/evidence трёх историй — статический модуль на фронте (`features/flag/contractStories.ts`);
  бейдж/методика собираются из этих данных + нейтральной рамки i18n (`frame.signal`, `flag_state.*` — уже есть,
  паритет с серверным `render`).
- Данные контракта (карточка) — реальные из seed (DEMO-0001 есть; добавить DEMO-0002/0003).
[Source: agents — schema.gen.ts/httpapi/contracts.go/registry/render; epics.md:1360,1505; architecture.md hot/cold]

### registry/render и нейтральность (Story 1.4)

- Нейтральная рамка существует: `registry/values/glossary-*.json` → `frame.signal` = «сигнал, требующий
  проверки»; `flag_state` = `raised/not_raised/insufficient_data/not_published`. На фронте они уже в
  `chrome.json` (`frame.signal`, `flag_state.*`) — **переиспользовать**, не дублировать смысл.
- `taboo_lexicon.json` — запрещённые корни (RU/KK); CI `ci-registry.yml` (doc-нейтральность) и go-тесты
  (`render_test.go` `TestNeutrality_*`) красят merge при совпадении. Любая новая проза флага/метки —
  нейтральна (через taboo-фильтр мысленно при написании).
- `flag_state: not_published` — закодированное состояние «флаг не прошёл gate» — структурная опора AC2.
- **Числа в прозе запрещены** (порог ×1.5 — данные методики, не текст бейджа). [Source: server/internal/{registry,render}; architecture.md:672; epics.md:898–916]

### Гардрейлы (несущие)

- **Нейтральность:** флаг — «сигнал, требующий проверки», НИКОГДА «нарушение/коррупция/виновен»; амбер
  (`--color-signal-attention`), **не алый**; глиф «!»; равная весомость с голубым; «недобросовестный/жосықсыз»
  — только как цитата названия РНУ. [DESIGN.md:389–395,609–612; UX-DR8/27/39]
- **Честность над домыслом:** ≥1 история — реальное честное состояние; 404 → «нет данных по объекту»;
  методика «недостаточно данных» (<5) показывает формулу/пороги всегда («отсутствие сигнала ≠ всё чисто»);
  не интерполировать. [epics.md:1015–1017; UX key-flag-methodology B]
- **Достижимость защитных связей (gate):** флаг публикуется ТОЛЬКО рядом с (а) путём к методике И (б) дверью
  «Сообщить об ошибке»; иначе не показывать — на любой поверхности. [AR-14; UX-DR28; epics.md:1011–1013]
