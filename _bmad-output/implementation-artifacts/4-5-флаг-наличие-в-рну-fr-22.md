## Story

As a **система AshyqQala.kz (compute-ядро)**,
I want **помечать Подрядчика (БИН) нейтральным флагом, когда у него АКТИВНАЯ запись в реестре недобросовестных участников (РНУ): `start_date ≤ сейчас` и `end_date` пуст/в будущем — с авто-снятием по `end_date` и полным `evidence` (ссылка на реестр + дата записи)**,
so that **гражданин/журналист видит государственный факт со ссылкой на первоисточник (UJ-3, FR-14), а по истечении записи флаг снимается сам (не «навечно») — атрибуция государству, НЕ оценка платформы**.

> **Тип истории:** флаг-история Эпика 4 (compute, **backend-only**). Реализует FR-22 поверх `risk_flags`/`RiskFlagStore` (Story 4.2 + contractor-путь Story 4.4). **Гардрейл эпика:** выход НЕ виден пользователю и НЕ «опубликованный флаг» — приёмка на ДАННЫЕ. [Source: epics.md:1465-1479, 1594; prd.md#FR-22:246-247]
>
> **⚠️ Sprint Change (прецедент 4.2/4.3/4.4):** Epic 4 «🚫 ожидает токен» (`epics.md:1385-1387`: РНУ FR-22 — живой ows_v2 `/v2/rnu`). По решению владельца (2026-06-24, [[sprint-sequencing-epic1-first]]) флаги строятся на СИНТЕТИКЕ + честный дескоуп живых данных. 4.5 строит ЧИСТУЮ дата-зависимую логику флага РНУ + evidence + интеграцию с `risk_flags` (contractor-субъект) + таблицу `rnu_entries` (схема) на синтетических записях; ЖИВОЙ импорт `/v2/rnu` (Epic 2) — ДЕСКОУП.

> **🔑 ЧТО НОВОГО в 4.5 (НЕ как 4.2/4.3/4.4):**
> 1. **Первый ДАТА-ЗАВИСИМЫЙ флаг** — использует `clock.Clock` (поле `Inputs.Now`, висевшее в каркасе с 1.10 без потребителя). Авто-снятие по `end_date` = простая ре-оценка с текущим clock. Даты в Inputs — `*int64` unix-секунды (ядро НЕ импортирует `time`, как `benchmark.Sample`).
> 2. **`flag.rnu.enabled` ОТСУТСТВУЕТ в `methodology_params.v1.yaml`** (есть только single_participant/price_per_km/monopoly) — НАДО добавить + расширить `methodology.go` (kill-switch, `*bool` honest-fail как single_participant). Это ОТЛИЧИЕ от 4.4 (где пороги уже были в YAML).
> 3. **НЕТ insufficient при отсутствии записи.** Реестр АВТОРИТЕТЕН: нет записи РНУ ИЛИ запись истекла → `not_raised` (определённый отрицательный факт), НЕ `insufficient_data` (в отличие от цены/монополии, где отсутствие данных = недостаточно). insufficient — ТОЛЬКО при битой записи (нет `start_date`).
> 4. **НОВАЯ таблица `rnu_entries`** (миграция 0008) — источник флага (как `price_benchmarks` для 4.3). risk_flags — переиспользует contractor-путь 4.4 (НОВЫХ risk_flags-запросов НЕ нужно).

## Acceptance Criteria

**AC1 — Чистый дата-зависимый флаг RNU: `(entry, now, params) → (FlagState, evidence)`; kill-switch из methodology_params**
**Given** ЧИСТЫЙ пакет `internal/flags` + `methodology_params.flag.rnu.enabled` (НОВЫЙ параметр, добавить в YAML+loader) + входы РНУ-записи (start_date/end_date как `*int64` unix, ссылки реестра) + `Inputs.Now` (clock.Clock — детерминизм, без `time.Now`)
**When** `enabled=true`, `start_date ≤ now` и (`end_date` nil ИЛИ `end_date > now`)
**Then** возвращается `registry.FlagRaised`; `evidence` (структура) хранит ВСЕ входы: `goszakup_rnu_id`, `start_date`, `end_date`, `source_url`, `reason_ref`, `enabled`, `methodology_version`; пакет `flags` остаётся ЧИСТЫМ (`make check-core` зелёный — НЕ импортирует `time`, время только через `Inputs.Now`).
[Source: prd.md#FR-22:246-247; epics.md:1473-1475; data-model §1:55, §2:81; architecture.md:298 (clock); CLAUDE.md «attribution to state»]

**AC2 — Авто-снятие по end_date + честные состояния (реестр авторитетен)**
**Given** идемпотентный пересчёт с текущим clock
**When** `end_date` наступил (`≤ now`) → `FlagNotRaised` (авто-снятие, НЕ «навечно»); `start_date > now` (запись ещё не активна) → `FlagNotRaised`; нет записи РНУ у БИН → `FlagNotRaised` (определённый отрицательный факт — реестр авторитетен, НЕ insufficient); `enabled=false` (kill-switch) → `FlagNotPublished` (методика отключила — не «всё чисто»); битая запись (`start_date` nil) → `FlagInsufficientData` (честно, не выдуманный факт)
**Then** однозначность: `raised` ⟺ (enabled, start ≤ now, end nil/будущее). Property-тест с `clock.Fixed`; авто-снятие доказуемо (та же запись, clock после end_date → not_raised).
[Source: prd.md#FR-22:247; epics.md:1477-1479; data-model §2:81 (авто-снятие по end_date); architecture.md:160 (граничные честны); CLAUDE.md «honesty over inference»]

**AC3 — Детерминизм через clock (без `time.Now`); граница дат**
**Given** ядро берёт «сейчас» ТОЛЬКО через `Inputs.Now` (clock.Clock), даты — `*int64` unix-секунды (НЕ `time.Time` в Inputs)
**When** сравниваются `start_date`/`end_date` с now
**Then** сравнение ДЕТЕРМИНИРОВАНО (тот же clock + те же даты → тот же результат бит-в-бит); `Inputs.Now.Now().Unix()` без импорта `time` в `flags` (как `benchmark.GroupMedian`); граница зафиксирована: `start == now` → активна (≤); `end == now` → снята (end > now строго для активности). go-list-страж `make check-core` зелёный.
[Source: architecture.md:298, 736 (clock/детерминизм); server/internal/benchmark/benchmark.go (паттерн clock без time-импорта); server/internal/clock/clock.go (Real|Fixed)]

**AC4 — Источник `rnu_entries` (новая таблица) + интеграция с risk_flags (contractor) + дескоуп живого /v2/rnu**
**Given** НОВАЯ таблица `rnu_entries` (миграция 0008; `organization_id` BIGINT без FK — AR-4, `goszakup_rnu_id`, `start_date`, `end_date` null, `reason_ref`, `source_url`) + `risk_flags` contractor-путь (Story 4.2/4.4) + `recalc.Run`

### Несущие ограничения / гардрейлы

- Чистота ядра (`flags` не тянет store/pgx/`time`); флаг — чистая функция, время через `Inputs.Now` (clock). `make check-core` (`-count=1`). [architecture.md:298, 775-776]
- Флаг — СТРУКТУРА (evidence все входы + ссылка реестра) + render; версия в evidence == params. [architecture.md:591-592, 647]
- **Атрибуция государству (несущий репутационный гардрейл):** РНУ — государственный факт со ссылкой; «недобросовестный» только как цитата названия реестра; платформа НЕ оценивает. [prd.md#FR-14/§7.1; data-model §2:81]
- Honesty: нет записи ИЛИ истекла → not_raised (реестр авторитетен, НЕ insufficient); битая запись → insufficient; авто-снятие по end_date (не «навечно»). [prd.md#FR-22; CLAUDE.md]
- Backend-only: не публикуется (Epic 5). Приёмка на ДАННЫЕ. [epics.md:1594]
- Порядок: флаг ПОСЛЕ benchmark (контракт recalc.Run; РНУ benchmark не использует). [architecture.md:880-881]
- **delta-семантика провайдера (решение владельца 2026-06-25):** источник РНУ — таблица `rnu_entries`; пересчёт читает ВСЕ записи (raised активные / not_raised истёкшие). Org без записи не оценивается (not_raised по отсутствию).
