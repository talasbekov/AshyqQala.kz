# Story 4.6: Пересчитываемость, методика-данные и измеримость SM-C1

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a **третье лицо (журналист/ревизор) и команда платформы**,
I want **пересчитать любой флаг по ПУБЛИЧНОЙ методике (evidence + версия + пороги в БД-реестре), оспорить/подтвердить его через `flag_disputes`, и измерить точность флагов (SM-C1) через `/metrics` + экспортировать evidence для цитирования в СМИ**,
so that **флаг — проверяемый сигнал, а не обвинение: методика воспроизводима бит-в-бит, ошибки измеримы и видны, а формулировки гарантированно нейтральны (несущая юридическая защита, FR-23)**.

> **Тип истории:** ФИНАЛ Эпика 4 — консолидация/измеримость (compute, **backend-only**). НЕ новый флаг: закрывает пересчитываемость (FR-23) + измеримость SM-C1 поверх 4 готовых флагов (4.2–4.5). **Гардрейл эпика:** выход НЕ виден пользователю и НЕ «опубликованный флаг» — приёмка на ДАННЫЕ (SQL/Go-ассерт), не на экран. [Source: epics.md:1481-1503, 1594; prd.md#FR-23:252-257, SM-C1:388]

> **🔑 5 ДЕЛИВЕРАБЛОВ 4.6 (НЕ новый флаг — консолидация):**
> 1. **methodology_params DB-реестр наполнен + инвариант YAML↔DB** — таблица `methodology_params` (0005, append-only immutable) ПУСТА; засеять v1.0 из YAML (flatten → key/value) + cross-invariant `evidence.methodology_version == YAML == DB-реестр` (закрывает дескоуп 4.3/4.4 «наполнение DB-реестра + инвариант версии»).
> 2. **`flag_disputes` (миграция 0009, AR-28)** — статус верификации `raised/disputed/confirmed/withdrawn` на флаг.
> 3. **SM-C1 через `/metrics`** — доля флагов, некорректных при ручной проверке (из `flag_disputes`); доменный счётчик prometheus (в `internal/metrics`) + семантический тест.
> 4. **Экспорт evidence (AR-29)** — JSON + печатный текст любого флага (для цитирования в СМИ); чистый exporter, без UI (Epic 5).
> 5. **Surface-agnostic property-тесты** — нейтральность (ВСЕ 4 флага × состояния × 2 локали → ноль taboo); однозначность insufficient (`«недостаточно сопоставимых данных»` ⟺ `comparable_n < min_sample`); линтер «нет числовых литералов в шаблонах render» (числа — из methodology_params).
