# Story 1.6: i18n-каркас (KZ-дефолт) и обёртки-инкапсуляторы

Status: done

## Story

As a **гражданин**,
I want **интерфейс на казахском по умолчанию с переключением на русский, и обёртки, честно помечающие язык доменных данных и состояния данных**,
so that **платформа говорит на моём языке, не выдаёт чужой язык за родной и не маскирует пустоту** (KZ-дефолт + честность языка/состояний — структурой).

> **Тип истории:** enabler-story Эпика 1 (фронтовый каркас). FRONTEND-ONLY. Несёт NFR-6 (KZ-дефолт),
> FR-10 (пометка языка доменных данных, без машинного перевода) и честность состояний.
> **Предусловия выполнены:** `web/` (Vite+React+TS, токены 1.5, тема 1.5) существует; `shared/{i18n,ui,state}/`
> — каркас `.gitkeep`. Task 0-HALT не нужен.
> **Важно (скоуп):** сервер `internal/lang` и wire-конверт `{value,lang,is_fallback,resolution}` — **НЕ в этой
> истории** (позже). `<LangValue>` строится против СПЕЦ-формы конверта (живые данные подключатся позже);
> honest-state enum (value_state/flag_state) уже доступен в `schema.gen.ts` — `<DataState>` к нему подключается.

## Acceptance Criteria

**AC1 — i18next `chrome`: KZ-дефолт, RU-фолбэк, `<html lang>`, Intl**
**Given** i18next namespace `chrome` (UI-строки платформы, отдельно от доменных данных)
**When** загружается приложение
**Then** `lng:'kk'`, `fallbackLng:'ru'`, `<html lang>` синхронизирован с активным языком (обновляется на `languageChanged`); числа/даты/₸ — через `Intl`. Локали `chrome` (kk+ru) — рукописные JSON (не codegen). Язык — только `kk`/`ru`, **никогда `kz`**.

**AC2 — Пометка языка доменных данных + бейдж фолбэка**
**Given** доменное значение со спец-формой `{value, lang, is_fallback, resolution}` (`lang∈{kk,ru}`; `resolution∈{original_kk, source_ru_shown_as_fallback}`; `machine_translated` — **запрещён в MVP**)
**When** ru-наименование показано внутри kk-карточки
**Then** оно обёрнуто `<span lang="ru">` (DOM `lang`-атрибут ОБЯЗАТЕЛЕН — иначе скринридер озвучит неверно); виден бейдж **«рус. источник» (RU) / «орыс дереккөзі» (KK)**; фронт НЕ переупорядочивает и не подавляет фолбэк (приоритет kk→ru решает сервер — позже).

**AC3 — Обёртки-инкапсуляторы `shared/`**
**Given** обёртки реализованы
**Then** есть: `<LangValue>` (билингв + DOM `lang` + бейдж фолбэка, по спец-форме конверта); `<DataState>` (автомат `idle|loading|empty|partial|error|success`, где `empty`=«нет данных»(no_data) ≠ `partial`=«недостаточно сопоставимых»(insufficient_sample); НИКОГДА «0»/прочерк/выдуманное; глифы из DESIGN); `<Icon name>` (типизированный ЗАКРЫТЫЙ `name`); `formatMoney`/`formatDate` (следуют языку chrome через `Intl`; **сырой `toLocaleString` запрещён lint**).

**AC4 — i18n-ось согласованности + lint-граница**
**Given** honest-state enum (value_state×11 / flag_state×4) из registry/OpenAPI (Story 1.4)
**When** прогон тестов/CI
**Then** локали `chrome` (kk И ru) содержат метку для КАЖДОГО honest-state (для `<DataState>`/меток), и тест проверяет это покрытие (i18n-ось); eslint-правило `no-restricted-syntax` красит сырой `toLocaleString`; всё в `ci-web.yml`.
