## Overall verdict

Сильная, добротно собранная пара спайнов: токены полностью резолвятся (0 битых ссылок,
светлая+тёмная пары везде, контраст указан для всех несущих сочетаний), компоненты покрыты
с двух сторон, гардрейлы нейтральности/честности проведены последовательно через оба файла,
три именованных Key Flow с кульминациями и путями отказа. Потребитель может извлечь данные
чисто. Что мешает «strong» по всем осям рубрики — несколько незакрытых несущих решений по
методике флагов (порог монополии и carve-out единственного участника схлопнуты в один `<5`;
окно медианы вообще не зафиксировано) и формальные дыры наследования (нет `sources:` во
фронтматтере EXPERIENCE.md; форма ошибки и страница района без собственных состояний). Внутри
самой рубрики все находки — medium и ниже; критичных и high нет.

Но три дополнительных адверсариальных ревьюера (нейтральность, доступность, карта-UX) меняют
картину и поднимают четыре critical. **Нейтральность** вскрывает 2 critical: названия флагов
«Монополия в регионе» и «Числится в РНУ» несут готовый обвинительный смысл в самом субъекте,
который суффикс «сигнал, требующий проверки» не нейтрализует — это рабочие заходы для иска о
деловой репутации (ст. 143 ГК РК). **Карта-UX** вскрывает 2 critical: поведение кластеризации
задано одной нечислимой строкой, а триггер фолбэка «гео <70%» не операционализирован — карта
объявлена «как 2GIS», но это лозунг, не спецификация. **Доступность** добавляет 3 high (контраст
ссылки/чипа на не-белых фонах ниже AA, статусы маркеров кодируются только цветом, доступность
canvas-карты для скринридера заявлена без механизма). Итог: несущие гардрейлы соблюдены по букве,
но юридический риск и реализуемость карты требуют правок до спринта реализации — не «переписать
всё», а закрыть конкретные дыры.

## Findings by severity

### Critical (4)

- **[Нейтральность]** — Название флага «Монополия в регионе» само по себе обвинительно (§EXPERIENCE.md:137, 174, 388). «Монополия» — термин с прямым антимонопольным значением; платформа считает «долю поставщика ≥50%» по своей выборке, это НЕ юридическая монополия; суффикс не лечит; повод для иска о деловой репутации (ст. 143 ГК РК). **Fix:** переименовать субъект в описание факта («Высокая концентрация контрактов у одного поставщика — сигнал, требующий проверки»); в методике оговорить «доля по выборке платформы, не вывод о доминирующем положении».
- **[Нейтральность]** — Флаг «Числится в РНУ» вшивает слово «недобросовестный» в UI (§EXPERIENCE.md:138, 206). Расшифровка реестра НЕДОБРОСОВЕСТНЫХ участников вшивает обвинительную оценку, запрещённую §7.1, по лицу, чей статус оспаривается. **Fix:** в UI «Есть запись в государственном реестре (РНУ) — сигнал…» со ссылкой на первоисточник; расшифровку давать только как цитату названия госреестра в методике, с атрибуцией государству.
- **[Карта-UX]** — Поведение кластеризации задано одной строкой и нечислимо (§EXPERIENCE.md Component Patterns {map-cluster}, Interaction Primitives). Нет clusterRadius, порога объединения, max-zoom раскрытия, спайдерфай совпадающих точек; при NFR-2 определяет «2GIS или каша». **Fix:** задать числовой контракт кластеризации (clusterRadius px, maxZoom, поведение совпадающих координат, supercluster-параметры) в §Карта или addendum.
- **[Карта-UX]** — Триггер фолбэка «гео-покрытие района <70%» не операционализирован (§EXPERIENCE.md State Patterns, §Карта: режимы и поведение). Не определён знаменатель, момент вычисления, поведение при панораме в район <70%; это прямой геогейт runbook (OQ-4/FR-6). **Fix:** серверный per-район флаг `geo_coverage`, правило перехода на уровне страницы района (не при панораме), явный обратный путь «всё равно показать карту».

### High (9)

- **[Нейтральность]** — Нейтральность KZ-перевода не валидируется; одна формулировка уже хромает (§EXPERIENCE.md:134–138, 141, 153). KZ — язык по умолчанию, но список запретов задан только по-русски; «картада нүкте жоқ» читается как дефект объекта. **Fix:** KZ-колонка в таблице запретов; нейтральность-ревью KZ носителем-юристом; «картадағы нүкте әзірге жоқ».
- **[Нейтральность]** — Форма «сообщить об ошибке» спрятана в подвал, недостижима с поверхностей распространения (§EXPERIENCE.md:70, 99; PRD:315). Несущий досудебный инструмент (§7.1, FR-28) недостижим с Telegram-пуша, OG, превью-листа; право ответа на MVP отсутствует. **Fix:** ссылка рядом с КАЖДЫМ бейджем; deep-link из Telegram-пуша; упомянуть канал в OG/целевой странице.
- **[Нейтральность]** — Бейдж флага на OG/пуше — голое утверждение без методики и пересчёта (§EXPERIENCE.md:174, 71/314, 310). OG и пуш несут формулировку флага без интерактива «тап → методика», ломая FR-23; эти артефакты расходятся вирусно. **Fix:** OG и пуш обязаны нести нейтральную формулировку с суффиксом + ссылку на первоисточник goszakup и на методику/пересчёт; требование к серверному OG-рендеру и шаблону пуша.
- **[Доступность]** — Ссылка-первоисточник на фоне sunken даёт 4.28:1 — ниже AA 4.5:1 (§DESIGN.md Colors/link, components.source-link). {link} #0F7DA3 на {surface-sunken} #EEF6F9; DESIGN.md заявляет «(4.7:1)» без оговорки фона. **Fix:** затемнить {link} (~#0E6E90) ИЛИ «ссылка только на белом {surface}» ИЛИ всегда подчёркивать.
- **[Доступность]** — Статусы маркеров кодируются только цветом, цвета неразличимы — WCAG 1.4.1 (§DESIGN.md components.map-marker-point; EXPERIENCE.md «Маркер-точка»). Синий/амбер/золото попарно ~1.3–1.4:1; для дальтоника амбер и золото совпадают, «есть флаг» неотличимо от «обычного». **Fix:** не-цветовой признак — иконка «!» в пине, отличная форма/обводка для выбранного, текст в alt и в кластерах.
- **[Доступность]** — Доступность canvas-карты MapLibre для SR/клавиатуры заявлена без механизма (§EXPERIENCE.md Interaction Primitives, Accessibility Floor). Маркеры на `<canvas>` не в дереве доступности; фолбэк-список включается только при сбое. **Fix:** DOM-маркеры (`maplibregl.Marker` с `<button aria-label>`) ИЛИ постоянный параллельный текстовый список объектов с фокус-таргетами ≥44px.
- **[Карта-UX]** — Деконфликт и приоритезация маркеров при плотности не описаны (NFR-2) (§EXPERIENCE.md). Нет z-index приоритета амбер-флагов, collision-detection, деградации плотности; флаги тонут или карта = стена пинов. **Fix:** z-order (выбранный > флаг > обычный), collision/declutter-политика, поведение «слишком плотно».
- **[Карта-UX]** — Перформанс-бюджет NFR-1 (<3с) не разложен на карту (§EXPERIENCE.md State Patterns, Cold load). Нет прогрессивной загрузки тайлов, стратегии загрузки маркеров (bbox vs всё), скелетона именно для карты. **Fix:** тайл-стратегия (vector tiles + on-demand), загрузка по bbox, map-specific загрузочное состояние.
- **[Карта-UX]** — «Без точки на карте» не имеет агрегированной аффордансы на самой карте (§EXPERIENCE.md State Patterns; Flow 1 сбой). {data-state-ungeocoded} помечает в списках, но карта молчит о неполноте; бьёт по честности. **Fix:** счётчик-аффорданс «ещё N объектов без точки → открыть списком».

### Medium (18)

- **[State coverage]** — Форма «сообщить об ошибке» не имеет состояний нигде (§EXPERIENCE.md:70). Нет empty/отправка/успех/ошибка/валидация. **Fix:** строка в State Patterns или мини-блок поведения формы (поля, успех/ошибка, Directus-очередь).
- **[Inheritance discipline]** — Фронтматтер EXPERIENCE.md не содержит поля `sources:` (§EXPERIENCE.md:1–9). Downstream читает спайн, а не журнал. **Fix:** добавить `sources:` (PRD, addendum, use cases v4, data-model-and-flags, конкурсный документ, runbook — `.decision-log.md:16–23`).
- **[Inheritance discipline]** — Методика флагов схлопывает три разных порога в один `<5` (§EXPERIENCE.md:195, 288, 392). Data-model различает `median.min_sample=5` и `flag.monopoly.min_group_contracts=5` (разные ключи сопоставимости). **Fix:** развести пороги по флагам.
- **[Inheritance discipline]** — Не унаследован carve-out `single_participant.exclude_methods` (§data-model:75; EXPERIENCE.md:135, 283). Спайн флагует безусловно; downstream выставит ложные флаги на легитимных способах. **Fix:** строка про исключаемые способы закупки.
- **[Inheritance discipline]** — Окно медианы не зафиксировано (§data-model:76, 84; EXPERIENCE.md:283, Flow 3:380). Нет окна 24 мес скользящего и ключа сопоставимости; фильтр «12 месяцев» во Flow 3 может ввести в заблуждение. **Fix:** зафиксировать окно 24 мес и ключ; отделить от UI-фильтра периода.
- **[Нейтральность]** — Амбер-маркер кодирует «есть флаг» цветом в отрыве от слова (§DESIGN.md:197–198, 433; EXPERIENCE.md:175, 254). В массе голубых пинов амбер = «подозрительный объект» — семантический дрейф §7.1. **Fix:** амбер не должен доминировать как «тревога»; форма-метка «i»/«?»; зафиксировать в Do/Don'ts «амбер-пин ≠ горячая точка».
- **[Нейтральность]** — «Единственный участник» как ярлык склоняет к выводу о сговоре (§EXPERIENCE.md:135, Flow Айгуль:354). Участие единственного поставщика законно. **Fix:** «В закупке был один участник — сигнал…» (избегать «единственный»); в методике «возможен по законным основаниям».
- **[Нейтральность]** — `data-state-insufficient` через штриховой бордюр читается как «дефект» (§DESIGN.md:231–234; EXPERIENCE.md:195). Dashed = «черновик/проблема», против §7.4 (честная пустота без негатива). **Fix:** нейтральный сплошной светлый бордюр или без рамки.
- **[Нейтральность]** — Карточка подрядчика: нет требования первоисточника на КАЖДУЮ репутационную метку (§EXPERIENCE.md:65, 180, 206–207; PRD FR-13). Source-link общий, а метка РНУ и флаг монополии должны вести каждая на свой первоисточник; нет видимой формы «сообщить об ошибке» в зоне флагов. **Fix:** каждая метка — своя ссылка-первоисточник + локальная «сообщить об ошибке».
- **[Доступность]** — Выбранный чип фильтра: текст 3.95:1 и фон выбран/не-выбран 1.08:1 (§DESIGN.md components.filter-chip). Фильтр применяется немедленно без кнопки — пользователь теряет единственную обратную связь о состоянии. **Fix:** поднять контраст текста и/или не-цветовой маркер выбора (галочка, обводка, жирность).
- **[Доступность]** — Не-цветовое различие «флаг» vs «нет данных/недостаточно» неполно (§DESIGN.md data-state-*; EXPERIENCE.md State Patterns). Dashed-бордюр insufficient = 2.70:1; состояния опираются на тон. **Fix:** у каждого состояния своя иконка (флаг «!», nodata «–», insufficient «≈»/«<5»); усилить контраст бордюра.
- **[Доступность]** — Фокус-ринг обещан, но не специфицирован как токен (§DESIGN.md — токен отсутствует; EXPERIENCE.md State Patterns «Фокус»). Нативный ринг теряет контраст на {surface-sunken}. **Fix:** токен focus-ring (2px {primary-strong} с офсетом, ≥3:1 в обеих темах), обязательный для всех интерактивных целей.
- **[Доступность]** — Ловушка/возврат фокуса для модальных слоёв не описаны (§EXPERIENCE.md «Нижний лист превью», Interaction Primitives). Нет focus-trap, initial/return-focus; пользователь «проваливается» под лист. **Fix:** focus-trap + initial + return-focus для {preview-sheet} и модалки методики; `role=dialog`/`aria-modal`.
- **[Доступность]** — Tap-target 44px задан токеном, но карта/пины и переключатели язык/тема противоречат (§DESIGN.md spacing.tap-target, lang/theme-switch 9.5px). Визуальный размер ≠ цель. **Fix:** явно зафиксировать min 44px для переключателей; гарантированная hit-area для пинов и клавиатурный доступ к кластеру.
- **[Карта-UX]** — Зум-контролы и контролы карты не специфицированы поведенчески (§DESIGN.md вид; EXPERIENCE.md Interaction Primitives). Нет позиции (зона большого пальца), «моё местоположение»/«к Астане»/компас, поведения при нижнем листе. **Fix:** набор контролов, позиция, сдвиг при открытом {preview-sheet}.
- **[Карта-UX]** — Жестовые конфликты карта↔страница не разобраны (§EXPERIENCE.md). Не разведены скролл страницы и pan карты, детенты {preview-sheet}. **Fix:** жестовая модель: детенты листа, cooperative gestures, приоритет по зоне касания.
- **[Карта-UX]** — Дороги-полилинии: визуал есть, поведение выбора нет (§DESIGN.md {map-line}; EXPERIENCE.md Component Patterns). Нет selected-стиля линии, hit-area, линие-специфичных полей превью. **Fix:** selected-стиль (золотой stroke/casing), hit-tolerance, поля превью (длина, цена/км).
- **[Карта-UX]** — Полигоны районов и выбор района на карте не специфицированы (§EXPERIENCE.md IA, граф навигации). Не решено, рисуются ли границы, ховер/выбор, как выбираются именованные районы. **Fix:** решить про районные полигоны и KATO-границы, задать стиль и селект-аффордансу, либо отнести выбор к фильтрам/странице.

### Low (14)

- **[Flow coverage]** — Четвёртая роль (внутренние операторы Directus) без Key Flow (§.decision-log.md:31; EXPERIENCE.md 347–395). Омиссия защитима. **Fix:** одна строка, что операторский поток сознательно вне спайна.
- **[Component coverage]** — Три `data-state-*` не имеют строки именно в Component Patterns (§EXPERIENCE.md:191–196); покрыты в State Patterns. **Fix:** при желании строка-указатель в Component Patterns, иначе оставить.
- **[State coverage]** — «Страница района» без собственных cold-load/empty состояний (§IA:66; EXPERIENCE.md:205). **Fix:** строка состояния для пустого/загружающегося района.
- **[State coverage]** — «Объяснение методики флага» без состояния «выборки недостаточно» (§IA:68). **Fix:** уточнить, что методика показывает формулу даже когда сигнал не выставлен.
- **[Visual reference coverage]** — Принцип «спайн побеждает на конфликте» встречается дважды (§EXPERIENCE.md:115, 399–401). **Fix:** оставить — оба места осмысленны; при строгом чтении свести к одному.
- **[Bloat & overspecification]** — Семейство токенов `confirmed*` (×6) определено, но не используется (§DESIGN.md:37–39, 67–69, 316–320). **Fix:** привязать к UI «данные из первоисточника» либо убрать до появления потребителя.
- **[Нейтральность]** — Слова «нарушители/разоблачаем» в проектном лексиконе тона (§.decision-log:37; EXPERIENCE.md:128, 163). Пока не в UI. **Fix:** вычистить даже из внутренней рамки тона.
- **[Нейтральность]** — «Профиль уточняется» рядом с активным флагом создаёт асимметрию (§EXPERIENCE.md:151, 207). **Fix:** показывать рядом с флагом оговорку «профиль ещё дополняется».
- **[Нейтральность]** — Срок давности сигнала не покрыт для трёх флагов из четырёх (§EXPERIENCE.md:206, 281–294). РНУ авто-снимается, остальные могут висеть бессрочно. **Fix:** показывать дату/период расчёта и `methodology_version`.
- **[Доступность]** — `lang`-атрибуты для двуязычия не упомянуты (§EXPERIENCE.md Foundation, Voice and Tone). SR неверно произнесёт казахскую кириллицу. **Fix:** правило `lang` на корне + inline-фрагментах; переключатель обновляет `lang`.
- **[Доступность]** — Графический контраст (1.4.11) не проверялся; тонкие границы как носитель смысла (§DESIGN.md Colors, Elevation). border #D2E4EC на white = 1.31. **Fix:** явная область проверки в DESIGN.md; не использовать тонкие границы как единственный носитель смысла.
- **[Доступность]** — Честность «только ручной smoke» создаёт остаточный риск (§EXPERIENCE.md Accessibility Floor). Smoke пропускает контраст на не-белых фонах, цвет-как-код, SR на canvas. **Fix:** 3 дешёвые проверки — axe/Lighthouse одной страницы; навигация флоу с клавиатуры; проход скринридером по карте+карточке.
- **[Карта-UX]** — Детенты листа и превью «много объектов под кластером» не определены (§EXPERIENCE.md Component Patterns {preview-sheet}). **Fix:** вариант превью-списка для множественного попадания; промежуточный детент листа.
- **[Карта-UX]** — Клавиатурное управление картой без модели фокуса по маркерам (§EXPERIENCE.md Interaction Primitives/Accessibility Floor). **Fix:** сослать клавиатурный доступ к маркерам на фолбэк/список объектов в кадре.
